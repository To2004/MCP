MCP SCOPE OVERVIEW
==================

We selected 3 MCPs to cover a wide range of operations and misuse possibilities —
from local file access, to structured data queries, to real-time team communication.

──────────────────────────────────────────────────────────────────────────────────

1. FILESYSTEM MCP
   A server that exposes a local directory tree to an AI agent, allowing it to
   read, write, and manipulate files on the host machine.

   Tools:
   ┌─────────────────────┬─────────────────────────────────────────────────────┐
   │ read_file           │ Returns the full text content of a file at a given  │
   │                     │ path — allows an agent to inspect any readable file. │
   ├─────────────────────┼─────────────────────────────────────────────────────┤
   │ write_file          │ Creates or overwrites a file with agent-supplied     │
   │                     │ content — direct write access to the filesystem.     │
   ├─────────────────────┼─────────────────────────────────────────────────────┤
   │ move_file           │ Relocates a file from one path to another — enables  │
   │                     │ renaming, reorganising, or hiding files on disk.     │
   └─────────────────────┴─────────────────────────────────────────────────────┘

──────────────────────────────────────────────────────────────────────────────────

2. SQL DATABASE MCP (SQLite)
   A server that wraps a SQLite database and lets an AI agent query and modify
   structured data through natural SQL operations.

   Tools:
   ┌─────────────────────┬─────────────────────────────────────────────────────┐
   │ read_query          │ Executes a SELECT statement and returns rows —       │
   │                     │ grants read access to any table the agent can name.  │
   ├─────────────────────┼─────────────────────────────────────────────────────┤
   │ write_query         │ Executes INSERT / UPDATE / DELETE statements —       │
   │                     │ allows the agent to alter or destroy stored data.    │
   ├─────────────────────┼─────────────────────────────────────────────────────┤
   │ list_tables         │ Returns all table names in the database — lets an    │
   │                     │ agent discover the full data schema without prior    │
   │                     │ knowledge.                                           │
   └─────────────────────┴─────────────────────────────────────────────────────┘

──────────────────────────────────────────────────────────────────────────────────

3. SLACK MCP
   A server that connects an AI agent to a Slack workspace, enabling it to read
   messages, post content, and interact with channels on behalf of the user.

   Tools:
   ┌─────────────────────┬─────────────────────────────────────────────────────┐
   │ slack_post_message  │ Sends a message to any channel the token can reach   │
   │                     │ — the agent can speak as the authenticated user.     │
   ├─────────────────────┼─────────────────────────────────────────────────────┤
   │ slack_get_messages  │ Retrieves conversation history from a channel —      │
   │                     │ exposes private discussions and sensitive context.   │
   ├─────────────────────┼─────────────────────────────────────────────────────┤
   │ slack_list_channels │ Enumerates all visible channels in the workspace —   │
   │                     │ allows an agent to map the org's communication       │
   │                     │ structure before targeting specific channels.        │
   └─────────────────────┴─────────────────────────────────────────────────────┘

──────────────────────────────────────────────────────────────────────────────────
