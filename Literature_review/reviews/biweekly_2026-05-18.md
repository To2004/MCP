## New papers

### 1. AgentTrust: Runtime Safety Evaluation and Interception for AI Agent Tool Use
- **ID:** 77 · **Category:** 1 — MCP Security · **Relevance:** 10 (Essential)
- **Authors:** Yang, C. · **Venue:** arXiv preprint, 31 pp. · **Submitted:** 6 May 2026
- **arXiv:** <https://arxiv.org/abs/2605.04785>
- AgentTrust is a runtime safety layer that intercepts agent tool calls **before** execution and returns a structured verdict {allow, warn, block, review}. It combines a shell-deobfuscation normalizer, SafeFix safer-alternative suggestions, RiskChain multi-step attack-chain detection, and a cache-aware LLM-as-Judge for ambiguous calls. Reports 95.0% verdict accuracy on a 300-scenario internal benchmark and 96.7% on a 630-scenario adversarial benchmark, at low-millisecond latency. Released AGPL-3.0 and **ships as an MCP server for MCP-compatible agents**. This is the closest published match to the MCP risk-scoring project this cycle — it is exactly the "MCP-server-resident risk scorer/interceptor that emits allow/warn/block/review" architecture the thesis proposes, with empirical numbers to benchmark against.

### 2. Security Risks in Tool-Enabled AI Agents: A Systematic Analysis of Privileged Execution Environments
- **ID:** 78 · **Category:** 1 — MCP Security · **Relevance:** 8 (Very Relevant)
- **Authors:** Goel, H. · **Venue:** arXiv preprint (extended); short paper accepted at **IEEE COMPSAC 2026** · **Submitted:** 10 May 2026
- **arXiv:** <https://arxiv.org/abs/2605.09721>
- An architecture-centric risk taxonomy for tool-enabled cloud-hosted agents (the paper explicitly cites MCP as a tool-integration framework that raises credential and access-control questions). Six recurring risk categories: capability-intent mismatch, ambient authority leakage, indirect secret exposure, state persistence and propagation, prompt injection and instruction override, and composition / chaining risks. Backed by three deployment scenarios (coding agent with shell, CI/CD agent, enterprise agent) and a small (80-run) GPT-5.1 ReAct experiment showing baseline unsafe-behavior rates of 40–100% with lightweight mitigations driving 3 of 4 scenarios to 0%. Useful as a direct threat-taxonomy reference for the risk-scorer module — the six classes map cleanly onto MCP-server protection.

### 3. ComplexMCP: Evaluation of LLM Agents in Dynamic, Interdependent, and Large-Scale Tool Sandbox
- **ID:** 79 · **Category:** 2 — MCP Protocol / Architecture · **Relevance:** 6 (Moderately Useful)
- **Authors:** Li, Y.; Yang, X.; Wang, L.; Luo, W.; Chen, H. · **Venue:** arXiv preprint · **Submitted:** 11 May 2026
- **arXiv:** <https://arxiv.org/abs/2605.10787>
- ComplexMCP is an MCP-native benchmark with 300+ tools across 7 stateful sandboxes (office suites to financial systems) and a seed-driven architecture for deterministic environment perturbations and unpredictable API failures. Top LLMs stall under 60% task success vs. 90% human performance. Three diagnosed failure modes: tool-retrieval saturation as action spaces scale, over-confidence (skipping environment checks), and "strategic defeatism" (rationalizing failure). Not adversarial, but worth tracking — the failure modes it surfaces (especially tool-retrieval saturation) are exactly the conditions under which a runtime risk scorer must remain reliable.

### 4. ARGUS: Defending LLM Agents Against Context-Aware Prompt Injection
- **ID:** 80 · **Category:** 4 — Prompt Injection / Tool Poisoning · **Relevance:** 9 (Critical)
- **Authors:** Weng, S.; Feng, Y.; Zhang, J.; Xie, X.; Yu, J.; Liu, J. · **Venue:** arXiv preprint, 19 pp. · **Submitted:** 5 May 2026
- **arXiv:** <https://arxiv.org/abs/2605.03378>
- Two contributions: (a) **AgentLure**, a benchmark of context-dependent tasks and context-aware prompt injection attacks across 4 agentic domains and 8 attack surfaces — designed specifically to expose the limits of context-insensitive benchmarks; (b) **ARGUS**, a defense that builds an influence-provenance graph tracking how untrusted context propagates into each agent decision, and verifies before execution that the decision is justified by trustworthy evidence. Reduces ASR to 3.8% while preserving 87.5% task utility, and is robust against adaptive white-box adversaries. Strong reference for the intent-analyzer and behavior-monitor modules of the project.

## Themes this cycle

- **Runtime, pre-execution interception is the dominant defensive paradigm.** Both AgentTrust and ARGUS are runtime layers that gate tool calls *before* execution rather than post-hoc auditing. AgentTrust returns a 4-way verdict directly to the MCP client; ARGUS verifies provenance-based justification. The shift away from post-execution benchmarking is now mainstream — and AgentTrust validates the project's specific bet on an MCP-server-resident scorer.
- **Architectural / capability-level threat models are catching up to attack-level ones.** Goel's COMPSAC paper deliberately steps back from cataloging attack techniques and instead models risk as *capability-intent mismatch* and *ambient authority leakage* — i.e., even benign agents in over-privileged execution environments are unsafe. This complements the project's "score requests based on what they could do" framing.
- **Benchmark realism keeps tightening.** ComplexMCP demands stateful interdependent tools and unpredictable API failures; AgentLure demands context-dependent tasks. Prior benchmarks that assume one-shot context-insensitive tasks are being explicitly retired. Future risk-scorer evaluations need to clear both bars.
