## 🔧 API & SDK
### **Agent SDK separated from subscription pools (effective June 15)**
Programmatic Claude usage now bills against a dedicated monthly credit instead of your subscription's chat pool. Most Pro users will run through the $20 credit fast on coding agents; budget accordingly or move heavy automation to direct API billing.
**Do this now:** Audit any `claude -p`, Agent SDK, or Claude Code GitHub Actions usage and decide whether the new credit covers it or you need to switch to pay-as-you-go API billing.
[Source](https://www.digitalapplied.com/blog/anthropic-claude-credit-overhaul-june-15-2026)

### **Sonnet 4 and Opus 4 retired**
The original `claude-sonnet-4-20250514` and `claude-opus-4-20250514` model IDs were retired June 15. Any production pipeline pinning those exact strings will start failing.
**Do this now:** Grep your codebase for those model IDs and migrate to `claude-sonnet-4-6` or `claude-opus-4-8`.
[Source](https://platform.claude.com/docs/en/release-notes/overview)

### **Self-hosted agent sandboxes in public beta**
Tool execution can now happen inside an environment you control (your VPC, your network policies) while the agent loop stays on Anthropic's infra. Useful when agents need to touch internal services that can't be exposed publicly.
**Do this now:** If you've been blocked from rolling out Managed Agents over data-egress concerns, request beta access and pilot one workflow against a private MCP server.
[Source](https://tygartmedia.com/claude-updates-june-2026/)

## 🆕 New Features
### **Claude Fable 5 launched June 9 — then suspended June 12**
Anthropic released Fable 5 (a Mythos-class model with safety classifiers) on June 9, claiming >10% over Opus 4.8 on key benchmarks. Three days later, a U.S. government export-control directive pulled the model from all customers worldwide. Mythos 5 remains in Project Glasswing only.
**Do this now:** Don't build production workflows around Fable 5 right now — fall back to Opus 4.8 and watch the [Anthropic news page](https://www.anthropic.com/news/claude-fable-5-mythos-5) for re-release terms.
[Source](https://techcrunch.com/2026/06/09/anthropic-released-claude-fable-5-its-most-powerful-model-publicly-days-after-warning-ai-is-getting-too-dangerous/)

### **Cowork 5-hour limits doubled through July 5**
Anthropic doubled the rolling 5-hour Cowork bucket on Pro, Max, Team, and legacy seat-based Enterprise plans, free, through July 5. Weekly caps are unchanged. Free and consumption-based Enterprise seats excluded.
**Do this now:** Run the longer-horizon Cowork tasks you've been deferring (multi-file refactors, long research jobs) before July 5.
[Source](https://thenewstack.io/anthropic-claude-cowork-promotion/)

### **Connector observability + in-app directory submission (public beta)**
Admins and owners can now monitor connector adoption, errors, latency, and usage across Claude products, and developers can submit MCP connectors to the directory directly from Claude.
**Do this now:** If you own connectors used by your org, turn on observability and check the error rate — bad connectors are usually the silent reason agents underperform.
[Source](https://releasebot.io/updates/anthropic)

## 🛠️ Tools & MCP
### **Claude Code 2.1.178: tool-param permission rules + nested subagents**
The June 15 release added `Tool(param:value)` permission syntax with wildcard support, so you can allow `Bash(git:*)` without unblocking `Bash(rm:*)`. Nested subagents (subagents that spawn their own subagents, capped at depth 5) also landed this week.
**Do this now:** Tighten your `.claude/settings.json` permissions to use parameter-scoped allowlists instead of whole-tool allows.
[Source](https://github.com/anthropics/claude-code/releases)

### **`/plugin list` and plugin search**
A new `/plugin list` command (with `--enabled`/`--disabled` filters) plus in-app plugin search make it easier to audit what's loaded in a long-lived Claude Code session.
**Do this now:** Run `/plugin list --enabled` in your main project to catch plugins you forgot you installed.
[Source](https://releasebot.io/updates/anthropic/claude-code)

### **Nested `.claude/skills` directory loading**
Skills inside nested `.claude/skills` directories now auto-load when you're working in that subtree. On a name clash, the nested skill appears as `<dir>:<name>` so both stay reachable.
**Do this now:** Move subproject-specific skills into the relevant subdirectory's `.claude/skills` instead of polluting your root config.
[Source](https://claudefa.st/blog/guide/changelog)

## 💡 Prompting Tips
### **Stop micromanaging Fable-class models**
Anthropic's Alex Albert: default to **high** or **xhigh** effort, rewrite your old CLAUDE.md instructions, and let the model use more judgment. Fable 5 (and by extension future Mythos-class releases) regress when you over-specify the steps — they're designed to own multi-step workflows, not be hand-held turn by turn.
**Do this now:** Pick one heavy CLAUDE.md file, delete the step-by-step prescriptions, and replace them with goal + reason + boundaries + verification criteria. Rerun your hardest task and compare.
[Source](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-fable-5)

### **Explain the *why*, not just the *what***
The June Fable 5 guide emphasizes that the model performs measurably better when you state the *purpose* behind a task. "Refactor this to use dependency injection because we want to mock the network layer in tests" beats "refactor this to use dependency injection."
**Do this now:** Add one sentence of motivation to your next non-trivial Claude prompt and see if the output requires fewer follow-ups.
[Source](https://knightli.com/en/2026/06/10/claude-fable-5-prompting-guide/)
