Same corpus (github_helios_org_100k.csv), same 5,000 scored calls, only the warm-up
length changes. p95 spread is over byte-identical repeated calls: calls that should
score identically and do not, because L's reference is still moving.

     20,000        0.012       0.012      0.526
     60,000        0.004       0.004      0.525

"before" and "after" are without and with the confidence shrinkage on L. The shrinkage
fixes what a fresh deployment CLAIMS -- it no longer escalates 6.4% on nine calls -- but
it does not shrink the spread, because the spread is the baseline adapting over a
5,000-call window, not an error. Any adaptive reference moves; the question is whether it
moves less than the signal.
