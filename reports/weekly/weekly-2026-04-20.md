## 💡 Prompting Tips

### **Context engineering has replaced prompt engineering**
Anthropic's own engineering post reframes the job as "finding the smallest set of high-signal tokens that maximize the likelihood of desired outcomes" — structuring the *whole* context window (system prompt, files, memory, examples, tool results) rather than micro-tuning a prompt string. Techniques that matter: compaction, structured note-taking, and multi-agent architectures for long horizons.
**Do this now:** Audit your top agent prompt — if it's a wall of instructions and XML tags, split it into INSTRUCTIONS / CONTEXT / TASK / OUTPUT FORMAT blocks and delete filler.
[Source](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)

### **The 2024 playbook now *hurts* on 4.6/4.7-class models**
"Think step by step" reportedly degrades output on current Claude models. Heavy role prompting ("You are a senior engineer with 20 years…") and verbose XML scaffolding are similarly counter-productive. Start with the simplest explicit instruction and only add structure when outputs miss.
**Do this now:** Delete "think step by step" and legacy role preambles from your prompts this week; A/B the cleaner versions.
[Source](https://www.the-ai-corner.com/p/context-engineering-guide-2026)

### **Use `xhigh` effort for agentic coding, `high` for most intelligence-sensitive work**
The new effort parameter on 4.7 directly trades intelligence for tokens. Anthropic's guidance: default to `high`, reach for `xhigh` on hard coding and multi-step agents.
**Do this now:** Set `effort: "high"` as your default on Opus 4.7 calls; flip to `xhigh` only for the hardest tasks.
[Source](https://platform.claude.com/docs/en/about-claude/models/whats-new-claude-4-7)

### **The interview trick for under-specified tasks**
Instead of writing a long spec upfront, start with a minimal prompt and ask Claude to interview *you* about edge cases, implementation choices, and tradeoffs. Often surfaces requirements you'd have missed.
**Do this now:** Try "Before you start, ask me 5 questions that would most change your approach." on your next non-trivial task.
[Source](https://promptbuilder.cc/blog/claude-prompt-engineering-best-practices-2026)

## 🌟 Community & Use Cases

### **The Claude Code source-code leak (March 31)**
A 59.8 MB unobfuscated source map (`*.map`) slipped into a public npm package — ~513k lines of TypeScript across 1,906 files, live for about three hours. The cause: Bun emits source maps by default and `.map` wasn't excluded in `.npmignore`. The leak surfaced a 50-subcommand bypass vulnerability (fixed in 2.1.90) and spawned a cottage industry of "what we learned from reading Claude Code's internals" posts.
**Do this now:** Audit your own npm publishes — `.map` files in `package.json > files` or missing from `.npmignore` is an incredibly common packaging bug.
[Source](https://thehackernews.com/2026/04/claude-code-tleaked-via-npm-packaging.html)
